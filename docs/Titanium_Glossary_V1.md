# Titanium Glossary V1

The Titanium Glossary is the central terminology layer for the course.

## Source of truth

`src/data/glossary.ts`

## Initial entries

CTR, CPC, CPA, CVR, ROAS, CAC, LTV, GA4, GTM, PMax, Smart Bidding, Broad Match, Conversão, Bidding, Search, Impressão, Lead, Tracking, IA and E5.

## Authoring rule

When a future lesson introduces a new acronym or specialized platform term, add the definition to the central glossary before publishing the lesson.

A glossary card may contain:

- original term;
- translation;
- concise explanation;
- formula;
- practical example;
- caution or interpretation rule.

## UX rule

The inline trigger is subtle and must not interrupt reading. It opens only after explicit activation: click/tap or keyboard activation with Enter/Space. Hover and focus alone never open it. Interactive glossary triggers must never be nested inside another button.
