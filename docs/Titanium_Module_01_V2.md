# Módulo 01 V2 — Fundamentos de Tráfego e Aquisição

## Objetivo do módulo

Construir a base que permite ao aluno sair de “não sei o que estou vendo” para “consigo organizar o caminho, calcular as métricas fundamentais e localizar uma primeira quebra antes de agir”.

## Sequência oficial

1. **Aula 01 — O que realmente é tráfego pago**
   - tráfego;
   - pago x orgânico;
   - atenção x intenção;
   - clique;
   - destino;
   - aquisição em nível conceitual.

2. **Aula 02 — Como funciona a publicidade digital**
   - anunciante;
   - plataforma;
   - inventário;
   - campanha;
   - orçamento;
   - leilão conceitual.

3. **Aula 03 — Da impressão ao resultado**
   - impressão;
   - clique x visita;
   - conversão;
   - lead/cliente;
   - receita;
   - jornada mensurável.

4. **Aula 04 — As métricas fundamentais**
   - CTR;
   - CPC;
   - CVR;
   - CPA;
   - ROAS;
   - cálculo, significado e limite de cada métrica.

5. **Aula 05 — Como as métricas se conectam**
   - decomposição;
   - CPA ≈ CPC ÷ CVR quando a base é compatível;
   - upstream x downstream;
   - sintoma x causa;
   - diagnóstico antes da prescrição.

6. **Aula 06 — Titanium Lab 01**
   - caso integrado;
   - cálculo;
   - comparação de períodos;
   - localização da quebra;
   - próxima investigação.

## Avaliação

- cada aula possui prova própria com 10 questões A-D;
- aprovação da aula: nota mínima 9,0;
- o Lab também exige nota mínima 9,0;
- Prova Final do Módulo: 20 questões;
- aprovação do módulo: nota mínima 9,0.

## Materiais

Cada aula possui:

- Guia + Notas em PDF;
- Mapa Mental em imagem;
- visual explicativo principal;
- interações A-D com feedback imediato.

## Regra pedagógica

O módulo respeita a ordem Zero Assumption:

`fenômeno → nome → significado → cálculo → interpretação → relação → diagnóstico`

Aulas 02 e 03 não usam as métricas profissionais como pré-requisito. CTR, CPC, CVR, CPA e ROAS entram formalmente apenas na Aula 04.
