# Titanium Concept Dependency Map V1

## Regra Zero Assumption

Nenhum conceito pode ser cobrado, combinado ou usado como pressuposto antes de ter sido formalmente introduzido.

A progressão padrão é:

`fenômeno -> nome -> significado -> exemplo -> aplicação -> relação -> diagnóstico -> decisão`

O glossário é apoio contextual. Ele nunca substitui uma aula que ainda não ensinou o conceito.

## Aula 00 - Imersão

A Aula 00 ensina o sistema de aprendizagem. Ela não usa métricas profissionais como pré-requisito.

Pode usar linguagem comum:

- pessoa;
- movimento;
- visitante;
- venda;
- resultado;
- evidência;
- hipótese;
- investigação.

O Diagnóstico Inicial é exceção intencional. Ele mede o ponto de partida e pode apresentar termos ainda não ensinados. Durante o diagnóstico, o glossário não revela definições dentro das questões.

### Aula 04 - As métricas fundamentais

Introduz uma métrica por vez:

- CTR;
- CPC;
- CVR;
- CPA;
- ROAS.

Para cada métrica:

1. situação simples;
2. cálculo;
3. nome;
4. significado;
5. o que ela representa;
6. o que ela não representa;
7. pergunta A-D;
8. interpretação básica.

### Aula 05 - Como as métricas se conectam

Somente aqui começam diagnósticos combinando métricas.

Exemplo permitido depois da base:

`CPC estável + CVR caiu -> CPA tende a subir`

Introduz relações de causa e efeito e primeiros diagnósticos simples.

## Estados de um conceito

### NOVO

O conceito está sendo apresentado pela primeira vez. A aula deve parar e ensinar.

### EM CONSOLIDAÇÃO

O conceito já foi ensinado, mas ainda recebe contexto, repetição e prática.

### PRÉ-REQUISITO

O conceito já foi ensinado e avaliado. Pode aparecer naturalmente em problemas mais avançados.

## Regra editorial

Antes de escrever qualquer pergunta, pergunte:

> O aluno já recebeu toda a base necessária para raciocinar sobre isso?

Se a resposta for não, o problema é da aula, não do aluno.
